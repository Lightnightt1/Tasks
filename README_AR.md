# StudyGlass — تطبيق جدول الاختبارات والمهام

تطبيق تقويم عربي بتصميم أسود/أبيض/رصاصي مع تأثير زجاجي، ويعمل على الجوال والكمبيوتر.

## ماذا يفعل؟

- تقويم بالشهور مع **اسم/نوع وعدد** الاختبارات والمهام داخل كل يوم. اضغط اليوم لرؤية التفاصيل.
- إضافة اختبار أو مهمة (العنوان، التاريخ، الوقت الاختياري، المادة، ملاحظات، حالة الإنجاز).
- تعديل وحذف المواعيد ووضع علامة «تم الإنجاز».
- إحصاءات للشهر والمهام والاختبارات القادمة والمكتملة، وقائمة أقرب المواعيد.
- **بدون حساب**: حفظ محلي على نفس المتصفح فقط.
- **بعد تسجيل الدخول**: حفظ ومزامنة في حسابك عبر Supabase، وظهور البيانات عند الدخول من هاتف آخر بنفس البريد وكلمة المرور.
- يدعم إضافة الموقع للشاشة الرئيسية في iPhone وAndroid.

## تفعيل التخزين السحابي (مطلوب لمزامنة الأجهزة)

1. افتح مشروع Supabase الحالي الذي تستخدمه في TradeGlass.
2. افتح SQL Editor ثم New Query والصق محتوى الملف `schema.sql` ثم اضغط Run.
   - ينشئ جدول **planner_items** منفصلًا، ولا يعدل بيانات TradeGlass.
   - يفعل RLS لحماية مواعيد كل مستخدم بحيث لا يصل لبياناته إلا عبر حسابه.
3. افتح Authentication → URL Configuration → Redirect URLs واضف:
   `https://nizarkhalid2.github.io/StudyGlass/`
   - **لا تحذف** رابط TradeGlass الموجود في Site URL أو Redirect URLs.
   - في حال اخترت مستودعًا باسم آخر، استخدم رابط GitHub Pages المطابق له.
4. اتأكد أن Authentication → Providers → Email مفعَّل. قد يُطلب تأكيد البريد بعد إنشاء الحساب.
5. ملف `config.js` يحتوي بالفعل على **رابط مشروعك ومفتاح Publishable العام فقط**. لا تضع Secret Key أو service_role هنا.

**لا يمكن اختبار المزامنة مع بياناتك الحقيقية من دون تنفيذ SQL ووجود حساب مسجل.**

## نشره على GitHub Pages (تطبيق مستقل)

1. افتح GitHub وأنشئ مستودعًا جديدًا اسمه `StudyGlass` واضبطه على Public.
2. فك ضغط الملف ZIP وارفع **جميع الملفات داخل المجلد** إلى جذر المستودع. يجب أن يكون `index.html` في الجذر، وليس داخل مجلد فرعي.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
4. افتح: `https://nizarkhalid2.github.io/StudyGlass/` بعد اكتمال النشر.
5. اضغط «تسجيل الدخول» وأنشئ حسابًا أو ادخل بحساب Supabase لديك. إن كانت لديك مواعيد محلية قديمة، يمكنك نقلها إلى السحابة من شاشة الحساب.

**مهم:** لا ترفع الملفات إلى مستودع `Trade` القديم؛ سيحل StudyGlass محل TradeGlass! أنشئ مستودعًا مستقلًا.

## التشغيل المحلي

افتح `index.html` مباشرةً لحفظ المواعيد المحلية. للمزامنة والتشغيل كصفحة قابلة للتثبيت، استخدم HTTPS من GitHub Pages.

## ملفات مهمة

- `index.html`: الصفحة.
- `styles.css`: تصميم Glass الأسود/الأبيض/الرمادي.
- `app.js`: التقويم والمهام وتسجيل الدخول والمزامنة.
- `config.js`: بيانات Supabase العامة.
- `schema.sql`: جدول المهام وحماية الصفوف.
- `manifest.webmanifest`, `sw.js` والأيقونات: التثبيت والأوفلاين الجزئي.

## ملاحظات

- لا تُرفع المواعيد المحلية إلى السحابة تلقائيًا: يوجد خيار «نقل المواعيد المحلية إلى حسابك» لتجنب مشاركة البيانات عن غير قصد.
- في حال فشل حفظ موعد أثناء تسجيل الدخول، يظهر خطأ ولا تُغلق نافذة الإدخال؛ جرّب مجددًا عند عودة الاتصال.
- اتصال الشبكة مطلوب لمزامنة جهاز آخر. الخدمة السحابية تعتمد على إعدادات مشروع Supabase وتوفره.
